[#credential-type-http]
HTTP::
+
[cols="1,3"]
|===
| *Documentation Link* | https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Authentication[HTTP authentication^]
| *Type Value* | `http`
a| *Required Fields* a|
* `authScheme`: authentication scheme: `basic`, `bearer`, or `mtls`
* Scheme-dependent: +
  Basic: `username`: username; `password`: password +
  Bearer: `token`: bearer token +
  mTLS: `certificate`: client certificate (PEM); `privateKey`: client private key (PEM)
a| *Optional Fields* a|
* `headerName`: custom header name (Bearer only; defaults to `Authorization`)
* `rootCertificate`: CA / root certificate (PEM)
* `passphrase`: passphrase for an encrypted private key (mTLS)
* `skipVerify`: skip TLS verification (development only)
|===

For example, the `fields` object for an AWS credential (including the optional values) looks like this:

[source,json]
----
"fields": {
  "accessKeyId": "AKIAIOSFODNN7EXAMPLE",
  "secretAccessKey": "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY",
  "region": "us-east-1",
  "endpoint": "https://s3.us-east-1.example-cloud.com",
  "sessionToken": "FQoGZXIvYXdzEXAMPLESESSIONTOKEN1234567890abcdefEXAMPLE=="
}
----

The `fields` object for an HTTP bearer token looks like this:

[source,json]
----
"fields": {
  "authScheme": "bearer",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example.token",
  "headerName": "X-Api-Key",
  "rootCertificate": "-----BEGIN CERTIFICATE-----\nMIIDXTCCAkWgAwIBAgIJAExampleCertData...\n-----END CERTIFICATE-----",
  "skipVerify": false
}
----
