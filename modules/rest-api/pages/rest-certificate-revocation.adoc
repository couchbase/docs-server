[#common-behavior]
== Common Behavior

The following applies to every endpoint listed above:

* *Enterprise Edition only*. On Community Edition, each endpoint returns `400` with `This http API endpoint requires enterprise edition`.
* *Whole cluster on 8.5*. Before the whole cluster runs 8.5, each endpoint returns `404` with `CRL feature not yet enabled in this cluster`.
* `401 Unauthorized` if authentication fails.
* `403 Forbidden` if the user lacks the permission.
The body names the permission, for example `{"message":"Forbidden. User needs the following permissions","permissions":["cluster.admin.security!write"]}`.
* Endpoints that change settings or files can return `503` when the cluster cannot commit the change.
The message is either `Operation temporarily cannot be performed possibly due to loss of quorum` or `Exceeded retries due to conflicting operations, please retry`.
