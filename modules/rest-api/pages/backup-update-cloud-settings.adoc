= Update Cloud Settings for a Repository
:page-status: Couchbase Server 8.5
:description: The Backup Service REST API lets you change the cloud settings of an active repository.

[abstract]
{description}

[#http-methods-and-uris]
== HTTP Method and URI

----
POST /cluster/self/repository/active/<repository-id>/cloudConfig
----

[#description]
== Description

Cloud object storage can keep earlier versions of each backup object.
Use this endpoint to choose whether the Backup Service removes those earlier versions when a backup expires under the retention settings of the repository.

[#curl-syntax]
== Curl Syntax

----
curl -X POST http://<backup-node-ip-address-or-domain-name>:8097/cluster/self/repository/active/<repository-id>/cloudConfig \
  -u <username>:<password> \
  -d '{"retention_delete_versions": true}'
----

The username and password must identify an administrator with the Full Admin role.
In the URI, `<repository-id>` is the ID of the repository.

The request body is a JSON object that can contain the following field:

* `retention_delete_versions`.
Optional.
A boolean.
Specify `true` to remove the earlier object versions when a backup expires, or `false` to keep them.

[#responses]
== Responses

If the call succeeds, the Backup Service returns a success status code.

If the request is not valid, the call fails and the response contains an error message.
