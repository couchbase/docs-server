= Editing a Catalog
:description: pass:q[You can edit a catalog's connection details using the `/pools/default/externalCatalogs/<catalog-name>` REST API endpoint.]
:keywords: external catalog, rest api, apache iceberg, edit catalog
:page-edition: Enterprise Edition
:page-topic-type: reference

[abstract]
{description}
An external catalog defines a connection to an external Apache Iceberg catalog provider such as AWS Glue or a Nessie server.
For more information about external catalogs and collections, see xref:learn:data/external-catalogs-and-collections.adoc[].

== Description

To change a catalog's connection details, send a `PATCH` request to `/pools/default/externalCatalogs/<catalog-name>`.
`PATCH` applies a partial merge.
Only the fields you supply change, and every other field keeps its existing value.

You cannot change the catalog's `name`.
Couchbase Server rejects the request if you supply it, regardless of whether the value matches the catalog's current name.

`catalogType` only ever accepts `ICEBERG`, so there is no other value to change it to.

Couchbase Server does not block you from changing `catalogSource` to a different provider through this endpoint.
However, it does not clear or revalidate  leftover fields from the previous provider.
To switch a catalog to a different provider, drop and recreate it instead of changing `catalogSource` in place.

== HTTP Method and URI

----
PATCH /pools/default/externalCatalogs/<catalog-name>
----

== curl Syntax

[source,bash]
----
curl -X PATCH http[s]://<host>:<port>/pools/default/externalCatalogs/<catalog-name> \
  -u <username>:<password> \
  [-d <provider-specific-parameter>=<value>]
----

== Path Parameters

`catalog-name`::
Required.
The name of the catalog to edit.

== Parameters

You can change any provider-specific connection parameter, except `name`, `catalogType`, and `catalogSource`.

== Required Privileges

Your account needs the xref:learn:security/roles.adoc#external-catalog-admin[External Catalog Admin] role or xref:learn:security/roles.adoc#full-admin[Full Admin].

== Responses

200 OK::
Couchbase Server updates the catalog and returns its new stored definition.

400 Bad Request::
You supplied `name` in the request, or a parameter's value fails validation.
Couchbase Server returns a message describing the specific error.

404 Not Found::
No catalog with that name exists.

== Example

The following example changes the AWS signing region for `flights_catalog`:

[source,bash]
----
curl -X PATCH -u $CB_USER:$CB_PASS \
  http://node1.example.com:8091/pools/default/externalCatalogs/flights_catalog \
  -d sigv4SigningRegion=us-west-2
----

If successful, the call returns the catalog's updated definition, with `rev` incremented.

IMPORTANT: Editing a catalog does not take effect immediately.
A dependent external collection can keep using a catalog's old connection details for a short time after you edit the catalog.
Query nodes pick up catalog changes asynchronously.
