= Dropping a Catalog
:description: pass:q[You can drop a catalog using the `/pools/default/externalCatalogs/<catalog-name>` REST API endpoint.]
:page-edition: Enterprise Edition
:page-topic-type: reference

[abstract]
{description}
An external catalog defines a connection to an external Apache Iceberg catalog provider such as AWS Glue or a Nessie server.
For more information about external catalogs and collections, see xref:learn:data/external-catalogs-and-collections.adoc[].

== Description

Send a `DELETE` request to `/pools/default/externalCatalogs/<catalog-name>` to remove a catalog.

== HTTP Method and URI

----
DELETE /pools/default/externalCatalogs/<catalog-name>
----

== curl Syntax

[source,bash]
----
curl -X DELETE http[s]://<host>:<port>/pools/default/externalCatalogs/<catalog-name> \
  -u <username>:<password>
----

== Path Parameters

`catalog-name`::
Required.
The name of the catalog to drop.

== Required Privileges

Your account needs the xref:learn:security/roles.adoc#external-catalog-admin[External Catalog Admin] role or xref:learn:security/roles.adoc#full-admin[Full Admin].

== Responses

200 OK::
Couchbase Server drops the catalog.

404 Not Found::
No catalog with that name exists.

== Example

[source,bash]
----
curl -X DELETE -u $CB_USER:$CB_PASS \
  http://node1.example.com:8091/pools/default/externalCatalogs/analytics_catalog
----

If successful, the call returns an empty response.

WARNING: Dropping a catalog does not drop the external collections built on it.
Couchbase Server does not warn you before you drop a catalog with dependent collections.
A query against an orphaned collection eventually fails with error code 12057 (`Catalog information not found for external collection`).
Drop or repoint every dependent external collection before you drop its catalog.
