== Getting Cluster Level Options

You can retrieve the current cluster settings for the following options:

* `bleveMaxResultWindow`
* `bleveMaxClauseCount`
* `maxReplicasAllowed`

Use the following CURL command to retrieve the parameters.

include::partial$get-cluster-level-options.adoc[tag=source-get-cluster-options]

This returns a JSON object containing the option parameters:

[source,json]
----
{
  "status": "ok",
  "maxReplicasAllowed": 3,
  "bucketTypesAllowed": "membase:ephemeral",
  "collectionsSupport": true,
  "bleveMaxResultWindow": 10000,
  "bleveMaxClauseCount": 10000,
  "deploymentModel": "default",
  "scopedIndexesSupport": true
}
----
