= bleveMaxTerms
:description: The bleveMaxTerms setting limits the total number of term searchers that a single Search query can create on each Search index partition.

[.status]#Couchbase Server 8.5#

[abstract]
{description}

The Search Service creates a term searcher for each term it looks up to answer a query.
Queries such as wildcard, prefix, regular expression, and fuzzy queries can expand to many terms, so a single query can create many term searchers.
The `bleveMaxTerms` limit counts every term searcher in the whole query, which helps restrict the memory and CPU a single query can use.

The default value of the `bleveMaxTerms` setting is *1024*.
Set it to `0` or a negative number to remove the limit.

If a query needs more term searchers than the limit, the query fails with an error like the following:

----
TooManyTermSearchers [1025 > bleveMaxTerms, which is set to 1024]
----

The `bleveMaxTerms` setting works alongside xref:fts-advanced-settings-bleveMaxClauseCount.adoc[bleveMaxClauseCount], which limits the number of child clauses in each disjunction of a query.

You can override `bleveMaxTerms` for a single query with the `bleveMaxTerms` property of the query's `ctl` object.
For more information, see xref:search:search-request-params.adoc#bleve-maxterms[Search Request JSON Properties].

== Example

[source,console]
----
curl -XPUT -H "Content-type:application/json" \
  -u <username>:<password> http://<ip>:8094/api/managerOptions \
  -d '{
    "bleveMaxTerms": "4096"
  }'
----
