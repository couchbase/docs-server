== New Features and Enhancements in 7.6.12

The following new features are provided in this release.

=== Introducing Couchbase Fleet Manager

*Couchbase Fleet Manager* gives you a single self-hosted view of your Couchbase usage across your entire fleet: clusters, nodes, cores, and RAM.

It tracks it against your contracted entitlements. 
It runs entirely in your own environment with no data leaving your network, and supports air-gapped deployments. 
Telemetry is collected from Couchbase Server `7.6.12` and `8.0.3+`

For more information see xref:fleet-manager::introduction.adoc[] or xref:introduction:contact-couchbase.adoc[]
