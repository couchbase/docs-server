== Release 7.6.12 (May 2026)

Couchbase Server 7.6.12 was released in May 2026.
This maintenance release contains fixes to issues.

=== Analytics Service

[#table-7-6-12-Analytics-Service, cols="10,40,40"]
|===
| Issue | Description | Resolution

| https://jira.issues.couchbase.com/browse/MB-71453[MB-71453]
| Queries combining a LIMIT clause with an index-nested-loop join may return incorrect results.
The system failed to evaluate filter conditions on joined collections before applying the LIMIT.
This issue occurred when using the indexnl hint.
| Issue Resolved
|===

=== Cluster Manager

[#table-7-6-12-Cluster-Manager, cols="10,40,40"]
|===
| Issue | Description | Resolution

| https://jira.issues.couchbase.com/browse/MB-65348[MB-65348]
| The system now adds a Content-Type header to the Prometheus metrics endpoint.
The endpoint uses the PrometheusText0.0.4 format for better compatibility.
This improvement helps monitoring tools correctly identify the metrics data.
| Issue Resolved
|===

=== XDCR

[#table-7-6-12-XDCR, cols="10,40,40"]
|===
| Issue | Description | Resolution

| https://jira.issues.couchbase.com/browse/MB-71258[MB-71258]
| A race condition caused goroutines to hang indefinitely during replication pauses or deletions.
This occurred when clusters required a rollback to zero after a recent failover.
The fix ensures the backfill request handler correctly watches for termination signals.
| Issue Resolved
|===
