== Release 7.6.13 (November 2026)
Couchbase Server 7.6.13 was released in November 2026.

This maintenance release contains fixes to issues.

== Fixed Issues
{empty}

=== Data Service
[#table-7-6-13-Data-Service, cols="10,40,40"]
|===
|Issue |Description |Resolution

|https://jira.issues.couchbase.com/browse/MB-74514[MB-74514]
|The Memcached process stops serving front-end connections.
This occurs when more than 100 external LDAP authentication requests are queued.
The process remains active while background tasks continue to run.
|The system now manages the external authentication request queue to prevent process hangs.

|https://jira.issues.couchbase.com/browse/MB-74199[MB-74199]
|DCP streams might send an incorrect datatype for compressed documents with extended attributes.
The server decompresses the document but incorrectly retains the Snappy datatype bit.
Consumers may treat these mutations as corrupt and drop them.
|The server now removes the Snappy datatype bit when sending uncompressed payloads over DCP.

|https://jira.issues.couchbase.com/browse/MB-61385[MB-61385]
|Faulty CAS values in SET or DELETE operations can distort the `vbucket` `max_cas`.
This distortion affects conflict resolution during XDCR replication.
Legitimate mutations might be skipped or ignored as a result.
|The system now fails operations that exceed the future CAS threshold to protect `vbucket` integrity.
|===

=== Query Service

[#table-7-6-13-Query-Service, cols="10,40,40"]
|===
|Issue |Description |Resolution

|https://jira.issues.couchbase.com/browse/MB-73429[MB-73429]
|Scope-level user-defined functions and optimizer statistics could be deleted during upgrades.
This happened if the Cluster Manager was briefly unavailable during the migration process.
Affected nodes would return `Function not found` errors.
|The Query Service now retries Cluster Manager connections instead of assuming a bucket was deleted.
|===

=== XDCR

[#table-7-6-13-XDCR, cols="10,40,40"]
|===
|Issue |Description |Resolution

|https://jira.issues.couchbase.com/browse/MB-72304[MB-72304]
|Rebalanced nodes might use stale manifests if buckets are recreated while the node is out.
This can cause issues with document back-filling once broken mappings are fixed.
The issue persists until all source cluster nodes are upgraded.
|Upgraded nodes now handle rebalance operations even if replications were recreated during their absence.
|===
