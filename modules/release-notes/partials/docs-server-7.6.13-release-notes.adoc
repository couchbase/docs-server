== Release 7.6.13 (November 2026)

Couchbase Server 7.6.13 was released in November 2026.
This maintenance release contains fixes to issues.

== Fixed Issues
{empty}

=== Data Service

[#table-7-6-13-Data-Service, cols="10,40,40"]
|===
|Issue |Description |Resolution

|https://jira.issues.couchbase.com/browse/MB-74199[MB-74199]
|The server incorrectly advertised the Snappy datatype bit for uncompressed extended attributes.
DCP consumers treated these mutations as corrupt and dropped them.
This issue affected releases 7.6.0 through 7.6.12.
|The server now resets the datatype to exclude the Snappy bit when sending uncompressed `xattrs`.

|https://jira.issues.couchbase.com/browse/MB-61385[MB-61385]
|Faulty CAS values in meta operations could distort `vbucket` `max_cas`.
This distortion impacted conflict resolution and caused replication to skip legitimate mutations.
|The system now fails operations with CAS values exceeding the 65-minute future threshold.
|===

=== XDCR

[#table-7-6-13-XDCR, cols="10,40,40"]
|===
|Issue |Description |Resolution

|https://jira.issues.couchbase.com/browse/MB-72304[MB-72304]
|Rebalanced-out nodes could hold stale manifests if buckets were recreated while the node was away.
Stale manifests caused issues like incomplete document back-fills during replication.
|Upgraded nodes now handle rebalancing by cleaning stale manifest objects.
|===

=== Query Service

[#table-7-6-13-Query-Service, cols="10,40,40"]
|===
|Issue |Description |Resolution

|https://jira.issues.couchbase.com/browse/MB-73429[MB-73429]
|Scope-level user-defined functions and optimizer statistics were sometimes deleted during upgrades.
This occurred if the Cluster Manager was briefly unavailable during the migration process.
|The Query Service now retries during short outages instead of assuming a bucket was dropped.
|===
