== Release 8.0.4 (November 2026)
Couchbase Server 8.0.4 was released in November 2026.
This maintenance release contains fixes to issues.

== Fixed Issues
{empty}

=== Cluster Manager

link:https://jira.issues.couchbase.com/browse/MB-73874[MB-73874]::
A new internal setting makes a client certificate carrying the internal identity no longer enough to authenticate.
The request must also carry valid credentials.
This setting is switched off by default in version 8.0.4.
Adding a node with client certificate authentication now also asks for the administrator's username and password.

=== Data Service

link:https://jira.issues.couchbase.com/browse/MB-74514[MB-74514]::
The Memcached process hangs when more than 100 external LDAP authentication requests are queued.
The front end stops serving connections while background tasks continue to run.
This release fixes the thread management to prevent the hang.

link:https://jira.issues.couchbase.com/browse/MB-74199[MB-74199]::
Documents stored with compression and extended attributes could be streamed over DCP with an incorrect datatype.
The server decompressed the document but incorrectly advertised the Snappy datatype bit.
DCP consumers could treat these mutations as corrupt and drop them.
This issue is now resolved.

link:https://jira.issues.couchbase.com/browse/MB-61385[MB-61385]::
Faulty CAS values in metadata operations could distort the `vbucket` maximum CAS value.
This distortion affected conflict resolution and caused legitimate mutations to be skipped during replication.
The system now fails operations with CAS values exceeding the 65-minute future threshold.

=== Search Service

link:https://jira.issues.couchbase.com/browse/MB-70770[MB-70770]::
Document deletions may not be consistently reflected in the index in rare scenarios.
Stale entries could persist in the index after successful deletion from the Data Service.
This release ensures consistent reflection of deletions in the Search Service.

=== Tools

link:https://jira.issues.couchbase.com/browse/MB-73773[MB-73773]::
The query optimizer incorrectly pushed vector scans to the `ANN` index without a LIMIT clause.
This behavior caused degraded recall because only a fraction of matching documents were considered.
Vector indexes are now only considered sargable for `ANN` ordering when a LIMIT clause is present.

link:https://jira.issues.couchbase.com/browse/MB-73429[MB-73429]::
Scope-level user-defined functions and cost-based optimizer statistics could be deleted during upgrades from earlier releases.
This occurred if the Cluster Manager was briefly unavailable during the migration process.
The Query Service now handles Cluster Manager outages during upgrades to prevent data loss.
