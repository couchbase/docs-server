== Release 8.0.4 (November 2026)

Couchbase Server 8.0.4 was released in November 2026.
This maintenance release contains fixes to issues.

== Fixed Issues
{empty}

=== Cluster Manager

link:https://jira.issues.couchbase.com/browse/MB-73874[MB-73874]::
A new internal setting requires valid credentials for client certificates carrying the internal identity.
This prevents unauthorized administrative access via forged certificates.
The setting is switched off by default in this release.

=== Data Service

link:https://jira.issues.couchbase.com/browse/MB-74199[MB-74199]::
The server incorrectly advertised the Snappy datatype for uncompressed DCP mutations containing only extended attributes.
Consumers could treat these mutations as corrupt and drop them.
The server now resets the datatype bit.

link:https://jira.issues.couchbase.com/browse/MB-61385[MB-61385]::
Faulty CAS values in metadata operations could distort `vbucket` `max_cas` and affect conflict resolution.
The system now fails operations with CAS values exceeding the future threshold.
This prevents legitimate mutations from being skipped during replication.

=== Search Service

link:https://jira.issues.couchbase.com/browse/MB-70770[MB-70770]::
Document deletions were not reflected in the index due to stale events.
This caused minor discrepancies in document counts between FTS and KV.
The fix ensures consistent indexing of deletions.

=== Query Service

link:https://jira.issues.couchbase.com/browse/MB-73773[MB-73773]::
Queries using vector ordering without a LIMIT clause incorrectly used the `ANN` index.
This resulted in degraded recall because only a subset of documents was considered.
Vector indexes now require a LIMIT clause for `ANN` ordering.

link:https://jira.issues.couchbase.com/browse/MB-73429[MB-73429]::
Scope-level user-defined functions and statistics could be deleted during upgrades if the Cluster Manager was unavailable.
The Query Service now retries short outages instead of assuming bucket deletion.
This prevents permanent loss of functions and statistics.
