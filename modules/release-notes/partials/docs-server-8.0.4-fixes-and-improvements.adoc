=== Search Service

https://jira.issues.couchbase.com/browse/MB-70770[MB-70770]::
FTS system tests with nested documents showed item count mismatches.
Document deletions might not consistently reflect in the index during rare scenarios.
Stale entries may persist in the index after successful deletion from the KV layer.
This infrequent condition can cause minor discrepancies in document counts between FTS and KV.
These inconsistencies might affect count-based validations or system comparisons.
