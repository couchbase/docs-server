== Release 8.0.4 (October 2026)

Couchbase Server 8.0.4 was released in October 2026.
This maintenance release contains fixes to issues.

=== Fixed Issues
{empty}

=== Cluster Manager

https://jira.issues.couchbase.com/browse/MB-73874[MB-73874] ::
Couchbase Server now includes a cluster-level setting to require passwords for internal identity connections under mTLS.
This setting prevents unauthorized administrative access using only internal client certificates.
The feature is turned off by default in this release.
It provides a security boundary between clusters sharing the same certificate authority.

=== Data Service

https://jira.issues.couchbase.com/browse/MB-74199[MB-74199] ::
The system now removes the Snappy datatype bit when decompressing items for DCP `xattr`-only mutations.
This fix prevents `gocbcore` from dropping these mutations as corrupt.
The issue occurred when stored values were compressed and carried extended attributes.

https://jira.issues.couchbase.com/browse/MB-61385[MB-61385] ::
Couchbase Server now fails operations that provide a CAS value exceeding the `hlc_max_future_threshold`.
The default threshold is 65 minutes.
This prevents faulty CAS values from poisoning the `vbucket max_cas`.
The fix ensures consistent conflict resolution for XDCR and Last Write Wins.

=== Search Service

https://jira.issues.couchbase.com/browse/MB-70770[MB-70770] ::
The system now prevents document deletions from being inconsistently reflected in the index during rare failover scenarios.
A new per-partition monotonic sequence guard ensures that stale DCP events do not resurrect deleted documents.
This fix resolves occasional item count mismatches between the Data Service and Search Service.
