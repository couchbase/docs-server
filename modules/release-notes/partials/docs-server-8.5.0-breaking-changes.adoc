== Breaking changes 8.5.0 (Private Preview)

This section is a first-pass draft of behavioral changes found via Jira (see the note at the top of the Fixed Issues section above).
Couchbase Server 8.5.0 contains the following breaking change:




=== Cluster Manager

[#breaking-changes-850-cluster-manager]

*https://jira.issues.couchbase.com/browse/MB-67280/[MB-67280]*::

*Change to Bucket Priority Settings*
+
As part of improving background task scheduling, the legacy implementation has been replaced with a standardized, more advanced scheduler.
As a result, setting a bucket's priority to high or low no longer affects system behavior, and the option to set bucket priority has been removed from the UI.
+
Previously, task scheduling relied on a basic two-priority queue (high and low), which had limitations such as busy polling. The new scheduling mechanism eliminates these issues.
+
NOTE: Bucket priority settings are still available via the REST API and CLI, to maintain compatibility with existing customer scripts and tooling.
