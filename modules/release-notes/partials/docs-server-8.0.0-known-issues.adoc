== Index Service

*https://jira.issues.couchbase.com/browse/MB-68626/[MB-68626]*::

An issue was identified with the indexer crashing during training due to Out of Memory (OOM) errors. The problem is attributed to fetching random samples without throttling, causing excessive memory usage. The logs showed that a panic occurred when the system memory usage approached 80% of the available quota. It is suggested to reduce the number of index builds per request to manage memory more effectively. This change will be moved to version 8.0.1 to allow for better control of memory utilization during vector fetching. A related release note ticket has been created for documentation purposes.
