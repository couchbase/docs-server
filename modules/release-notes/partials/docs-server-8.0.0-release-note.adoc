== Release 8.0.0 (August 2025)

Couchbase Server 8.0.0 was released in August 2025.
This maintenance release contains fixes to issues.

== Fixed Issues

=== Storage

[#dlist-known-issues-800-storage]


*https://jira.issues.couchbase.com/browse/MB-60542/[MB-60542]*::

The Couchbase Server 8.0.0-1545 and Couchbase Columnar 1.2.0-1009 builds include a kv_engine commit with the message that addresses MB-60542. This update focuses on parsing and dumping "deprecated" and "notes" fields. The commit, identified by fd8914a, is linked to a specific GitHub commit and Jira ticket.

*https://jira.issues.couchbase.com/browse/MB-61385/[MB-61385]*::

This summary outlines the handling of invalid CAS (Compare-and-Swap) values in Couchbase's KV engine, focusing on preventing CAS poisoning, which can disrupt conflict resolution. MB-61385 introduces mechanisms to handle CAS values that exceed a defined threshold (default: 65 minutes). Two main strategies are provided: "error" mode, which rejects operations with invalid CAS, and "replace" mode, which regenerates the CAS value. The implementation includes counters to track invalid CAS occurrences, and offers separate configurations for DCP replication and front-end operations. The update emphasizes the importance of consistency between source XDCR and target KV to avoid issues in replication processes.

*https://jira.issues.couchbase.com/browse/MB-65644/[MB-65644]*::

Couchbase Server version 8.0.0-2772 includes an indexing commit that addresses issue MB-65644. The commit disables the plasma configuration setting `enableCompressFullMarshal` by setting it to false. This change is expected to be finalized in version 8.0.0-2905.


=== Data Service

[#dlist-known-issues-800-data-service]


*https://jira.issues.couchbase.com/browse/MB-62295/[MB-62295]*::

Couchbase-server build 8.0.0-1668 includes a change to the audit.log file, now using a symbolic link, as part of kv_engine commit db74893. This update addresses issue MB-62295 and has been validated on build 8.0.0-2236. The team requests additions to the release notes for builds using this commit. The symbolic link ensures seamless access to the current audit file, though users are not expected to notice the change.

=== Query Service

[#dlist-known-issues-800-query-service]


*https://jira.issues.couchbase.com/browse/MB-51623/[MB-51623]*::

The document describes an issue with expiration being returned incorrectly as 0, which should be retrieved through the sub-document API. In a JOIN operation, it's only obtained through a Fetch on the right side. The query utilizes a Legacy LOOKUP JOIN, leading to missing subpaths in the plan operator. Fixes are needed for LOOKUP JOIN (JOIN ... ON KEYS) and LOOKUP NEST (NEST ... ON KEYS), and there might be changes required for legacy Index Joins. The issue is addressed in couchbase-server-7.2.0-1050 with a query commit that enables subpaths with legacy joins. Comments for the release note are requested.

*https://jira.issues.couchbase.com/browse/MB-62793/[MB-62793]*::

The text discusses efforts to relax restrictions on the number of XATTRs in Couchbase Server queries, specifically within the context of indexing and querying. Despite attempting to lift these restrictions, an issue persisted, evident when creating an index with 16 XATTR expressions. Another point raised involves mixing XATTRs with document paths, which is typically avoided during early projection checks. The text mentions specific commits and builds where fixes and adjustments have been implemented, including updates in Couchbase Server versions 7.7 and 8.0.0. Release notes for version 7.7 are also being prepared to communicate these changes to customers.

*https://jira.issues.couchbase.com/browse/MB-63459/[MB-63459]*::

New to 7.7.0 is the ability to manipulate document extended attributes (xattrs) via common SQL++ statements.  

+

INSERT and UPSERT statement OPTIONS may now include an “xattrs” object element detailing additions and changes to the xattrs (omissions do not delete xattrs).  The UPDATE statement now supports SET and UNSET of meta().xattrs.{attribute} elements.


=== Eventing Service

[#dlist-known-issues-800-eventing-service]


*https://jira.issues.couchbase.com/browse/MB-64081/[MB-64081]*::

The issue with Eventing not working with App Services in Couchbase's Capella environment was identified as a problem with how the Sync Gateway registry object was parsed. Unlike on-prem deployments, the cloud deployment encases the registry in a "config" key, causing the parser to fail. Steps to reproduce involve specific versions of App Services and Eventing. Patches are in review and expected to address this by November 5th, with backporting planned. Testing on Capella previously hadn't covered this configuration, and new smoke tests are being added. Once approved, changes will be backported to version 7.6.4.


=== Backup Service

[#dlist-known-issues-800-backup-service]


*https://jira.issues.couchbase.com/browse/MB-62655/[MB-62655]*::

The query automatic workload report generator includes updates and commits related to Couchbase builds. Specifically, build couchbase-server-8.0.0-1845 and 8.0.0-1851 contain commits for creating and properly building the query-report-generator, referenced as [MB-62655]. A typo was identified in a report title where "Priority" was used instead of "Primary", leading to the creation of an issue [MB-64093]. Various builds, such as couchbase-columnar-1.2.0-1009, repeatedly include these commits. The tasks are noted to be moved from Morpheus to Ponyo.




=== Index Service

[#dlist-known-issues-800-index-service]


*https://jira.issues.couchbase.com/browse/MB-64982/[MB-64982]*::

In Couchbase Server 8.0.0-2495, a commit [de8d5f3] was made to disable the "nodes" clause for the alter index "replica_count" action when file-based rebalance is enabled. This change addresses issue [MB-64982]. The same commit is included in Couchbase Columnar 1.2.0-1009. The modification was validated on version 8.0.0-2634, and the ticket has been closed.
