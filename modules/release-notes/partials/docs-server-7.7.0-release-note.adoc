== Release cypher (May 2025)

Couchbase Server cypher was released in May 2025.
This maintenance release contains fixes to issues.

== Fixed Issues


=== Query Service

[#dlist-known-issues-cypher-query-service]

*https://jira.issues.couchbase.com/browse/MB-62793/[MB-62793]*::

The Couchbase team is addressing the issue of relaxing the maximum number of XATTRs in their system.
Even after removing certain restrictions,
attempts to create an index on 16 XATTR expressions and run queries still faced issues.
A particular difficulty arises when mixing XATTRs with document paths,
despite successful attempts using the Go SDK's LookupIn API.
