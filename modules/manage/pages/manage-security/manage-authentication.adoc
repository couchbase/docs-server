= Manage Authentication
:description: To access Couchbase Server, every user and application must be authenticated.

[abstract]
{description}
_Authentication_ is a process for identifying a user who is attempting to access a system.

Couchbase Server supports several authentication methods, and you can use more than one at a time.
This page links to the configuration steps for each.

For how the methods work and how to choose between them, see xref:learn:security/authentication-overview.adoc[Understanding Authentication].

== Native Authentication

Couchbase Server provides these methods itself and stores the credentials.
They are always available, and the first Administrator account on a cluster always uses a native username and password.

* xref:manage:manage-security/manage-native-passwords.adoc[Manage Native Passwords] --- set a password policy, change passwords, and issue temporary passwords that users must replace on first sign-in.
* xref:manage:manage-security/manage-certificates.adoc[Manage Certificates] --- set up X.509 client certificates so applications can authenticate with mutual TLS instead of a password.

== External Authentication

These methods check credentials against a system you already run, which means one place to manage accounts and one password policy.
See xref:learn:security/external-authentication.adoc[External Authentication Methods].

* xref:manage:manage-security/configure-ldap.adoc[Configure LDAP] --- authenticate against a directory server, including Microsoft Active Directory.
* xref:manage:manage-security/manage-jwt.adoc[JWT Authentication] --- accept signed tokens from an identity provider, and optionally let it supply each user's roles and groups.
* xref:manage:manage-security/configure-saml.adoc[Configure SAML] --- single sign-on for the Web Console.
* xref:manage:manage-security/configure-pam.adoc[Configure PAM] --- authenticate against the Linux host's own accounts.

== Related Tasks

* xref:manage:manage-security/manage-users-and-roles.adoc[Manage Users, Groups, and Roles] --- create users, put them into groups, and decide what each can do.
This is also where you lock an account to stop someone signing in.
* xref:manage:manage-security/manage-sessions.adoc[Manage Sessions] --- control how long a Web Console session lasts.
* xref:manage:manage-security/manage-console-access.adoc[Manage Console Access] --- restrict who can reach the Web Console.
