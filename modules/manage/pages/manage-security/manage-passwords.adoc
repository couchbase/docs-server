= Manage Passwords
:description: pass:q[Couchbase Server lets you manage passwords for local users, and enforce password policies.]
:page-toclevels: 3

[abstract]
{description}

Couchbase Server manages passwords for users in the local domain when password authentication is used.
The administrator, who installs and configures Couchbase Server, can create, reset, and enforce password policies for these accounts through the Web UI, CLI, or REST API.
Local user accounts also support additional security controls such as forced password changes, password expiration, and restrictions on password reuse.

For users in the external domain, credentials are managed by external authentication systems such as LDAP or SAML.
Couchbase Server relies on these systems to verify user identity, which means that password creation, storage, and policy enforcement occur outside of Couchbase.
This separation allows organizations to centralize identity management, apply consistent authentication policies across applications, and reduce administrative overhead.

[#user-password-changes]
== User Password Changes



Users defined in the local domain can change their own passwords directly through Couchbase Server.

If they have Web UI access, they can sign in and use the **Change Password** option from the account menu. They can also update their password through the CLI by using the `couchbase-cli user-change-password` command, or through the REST API by calling the `/controller/changePassword` endpoint.

This flexibility allows local users to manage their credentials without administrator involvement, which reduces administrative workload and improves security by ensuring that only the user knows their active password. In addition, Couchbase Server can enforce policies such as password expiration, reuse restrictions, and forced password changes to strengthen security for local accounts.

 






== Administrative Password Controls

[#reset-password]
=== Reset Password

You can reset any local user's password associated with your cluster.

To reset a local user's password, do the following:

. On the [.ui]*Security* screen, select [.ui]*Users & Groups*, and then select [.ui]*Users*.
+
image::manage-security/userSecurityRowClicked.png[,800,align=middle]
+
NOTE: The [.ui]*Reset Password* button only appears when the selected user is
locally defined.

. Select the user account from the list for which you want to reset the password and select btn:[Reset Password] associated with that user.
The [.ui]*Reset Password* dialog is displayed.
+
image::manage-security/resetPassword.png[,260,align=left]

. In the [.ui]*Reset Password* dialog, enter the new password for the user in the [.ui]*New Password* field and re-enter to confirm the password in the [.ui]*Confirm Password* field.

. Select btn:[Save] to save the password changes.

[#force-password-update-ui]
=== Force Password Update

You can force a password update for any local user associated with your cluster.

To force a local user to change their password, do the following:

. On the [.ui]*Security* screen, select [.ui]*Users & Groups*, and then select [.ui]*Users*.





. Select btn:[Save] to save the password changes.
