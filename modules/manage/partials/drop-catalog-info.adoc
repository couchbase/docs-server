Dropping a catalog does not cascade to any external collections that still reference it.
Nothing prevents you from dropping a catalog that still has dependents.
Once the drop finishes propagating, a query against an orphaned external collection fails with the error `"Catalog information not found for external collection"`.

If you're permanently removing the catalog's Iceberg tables from Couchbase Server, first drop its external collections.
Once you have removed them, drop the catalog.
Afterwards, you can drop any credentials you no longer need.
