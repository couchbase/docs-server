[CAUTION]
====
Couchbase Server does not warn you if the credential you're dropping is actively used.
For example, it does not determine if continuous backup relies on the credential to authenticate with its storage location.
Before dropping a credential, make sure it's not in use. 


If you're unsure whether a credential is in use, you can enable auditing of Credential Consumer user activities.
When this auditing is enabled, each attempt to use a credential is written to a log. 
The log entries include the ID of the credential being consumed.
This logging includes both the use of credentials on behalf of a user and direct use of a credential by a service.
After enabling auditing, wait for some period of time and then search for the credential ID to see if it has been used.
For more information, see xref:learn:security/auditing.adoc[].
====
