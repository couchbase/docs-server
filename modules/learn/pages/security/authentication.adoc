= Authentication
:description: pass:q[To access Couchbase Server, users must be authenticated. \
_Authentication_ is a process for identifying who is attempting to access a system.]
:page-aliases: security:security-authentication,security:security-ldap-new

{description}
Subsequent to successful authentication, _authorization_ can be performed, whereby the user's appropriate access-level is determined.

Couchbase Server can check credentials itself, using a _native_ method: a _username_ and _password_, or an _X.509 certificate_.
It can also delegate the check to a system you already run &#8212; an LDAP directory, a SAML or JWT identity provider, or the Linux host's own accounts through PAM.

Couchbase Server assigns each user to one of two _authentication domains_: the _local_ domain consisting of users whose credentials are maintained by Couchbase Server itself; the _external_ domain consisting of users whose credentials are maintained remotely.

* xref:learn:security/external-authentication.adoc[External Authentication Methods], which covers PAM, LDAP, SAML, and JWT.
