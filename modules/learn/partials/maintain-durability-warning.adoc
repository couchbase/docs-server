[WARNING]
.Potential Data Loss
====
Enabling `durabilityImpossibleFallback` degrades the guarantee that durable writes offer: that Couchbase Server has persisted the data in a way that should survive node failure.
When enabled for a bucket, this setting makes durable writes to it during a failover no more safe from data loss than regular asynchronous writes.
Also, because transactions require durable writes, enabling this setting means they do not provide the same guarantees as they do when `durabilityImpossibleFallback` is off.

Use this setting only in special cases such as when you're performing a graceful failover and you still want durable writes to succeed.
Always turn off this setting as soon as possible.
====
